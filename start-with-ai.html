Start With AI

Eight focus steps for one $20/month subscription. The problem with getting started isn't that there aren't enough resources — it's that there are far too many. So this is deliberately one path. Ignore everything else for thirty days.

  1. Pay for exactly one.Free tiers teach you that AI is a toy, because the free version is a toy. Pick one paid assistant and commit for a month. I use Claude — the $20/month plan (about $17 if you pay yearly). One tool you actually learn beats four you sample.
  2. Before you pay: I have a few free weeks to hand out.Claude gives subscribers a small number of guest passes — seven days of the paid plan, Claude Code included, free. Here's mine. Four things you should know before you click, because I'd want to know them: you'll have to put a card in (you won't be charged if you cancel inside the week), it only works if you've never paid for Claude before, if you do end up subscribing I get $10 in usage credits — so yes, I have a small stake in you clicking it — and I only have a handful, so if the link's dead by the time you read this, they're gone.
  3. Give it one job you already do.Not "learn AI." Pick a specific task that shows up every week and that you resent: the follow-up emails, the spreadsheet cleanup, the notes nobody reads. One job. A real one. That's your whole curriculum for week one.
  4. Get out of the chat window.The chat box is the demo, not the product. The step-change is Claude Code — the same subscription, running in your computer's terminal, where it can read and change your actual files instead of describing what you should do. It's included in the $20 plan. This is the single biggest jump available to you.
  5. Budget one bad afternoon.Getting set up is genuinely annoying — installing things, permissions, error messages you don't understand. That friction is the price of admission, not evidence you're not technical enough. Everyone pays it once. Put it on the calendar so it doesn't ambush you.
  6. Point it at your own files.Generic questions get generic answers. The moment it's working on your documents, your numbers, your half-finished projects, it stops being a novelty. Start it in the folder where your real work already lives.
  7. Use what other people already built.Most of what you want, someone has already made and given away — on GitHub, mostly, for free. You don't need to understand how to write it. You need to know it exists and how to point your assistant at it. Ask it to find and set one up for you.
  8. Watch the meter.Usage is shared between the chat app and Claude Code — heavy sessions in one leave less for the other. Type /status in Claude Code to see where you stand. Learning that rhythm early prevents the frustrating surprise of running dry mid-task.
  9. Keep a wins file, then cancel-test at thirty days.One line every time it saves you real time. At day thirty, read the list and ask honestly whether it earned the $20. If it didn't, cancel — you've lost one dinner out. If it did, you'll have the receipts, which is the only argument that survives a bad week.
What to skip for now
  • Comparison videos and "best AI tool" lists. They're built to keep you choosing instead of using.
  • Prompt-engineering courses. Talk to it like a competent coworker; that's most of it.
  • Building your own custom setup before you've used a plain one for a month.
  • A second subscription. Adding tools is what overwhelm feels like from the inside.
The takeawayThe point isn't to learn AI. The point is to hand off the forty minutes of work you hate and get that time back. Pick one job, pay for one tool, suffer through one setup, and give it thirty days. Everything else on the internet can wait.
